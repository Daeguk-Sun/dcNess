# PRD — 연락처 CSV 가져오기 (발췌)

운영자는 명령줄 도구로 연락처 CSV 파일을 서비스 DB 에 넣는다.

## Must

- M1. 운영자는 `contacts import <file> --dry-run` 으로 파일의 행 수를 확인한다.
- M2. 형식이 잘못된 행이 있으면 도구는 행 번호와 이유를 출력하고 DB 에 아무것도 쓰지 않는다.
- M3. 모든 행이 올바르면 도구는 연락처를 DB 에 쓰고 쓴 행 수를 출력한다.

## 결정

- 사용자 확정: 잘못된 행이 하나라도 있으면 전체 가져오기를 중단한다(부분 가져오기 없음).
- 사용자 확정: 이메일 열이 비어 있거나 `@` 가 없으면 잘못된 행이다.
