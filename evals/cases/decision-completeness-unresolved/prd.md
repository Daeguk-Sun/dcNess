# PRD — 비용 요청 승인

## 대상 사용자

소규모 조직의 구성원과 비용 승인 담당자.

## 목표

구성원이 비용 요청을 제출하고 승인 결과와 반려 이유를 확인할 수 있게 한다.

## 기능별 스펙

### 요청 제출과 승인

- 구성원은 금액, 용도, 증빙을 입력해 요청을 제출한다.
- 승인된 요청만 지급 대기 상태로 전환한다.
- 승인 담당자의 범위, 여러 담당자가 있을 때의 우선순위, 담당자 부재 시 대리 승인 범위는 구현하면서 정한다.

## 실패와 복구

- 반려 시 이유를 구성원에게 보여주고 수정 후 재제출할 수 있다.

## 기술 검토 필요 영역

해당 없음.
