# PRD — 비용 요청 승인

## 대상 사용자

소규모 조직의 구성원과 비용 승인 담당자.

## 목표

구성원이 비용 요청을 제출하고 승인 결과와 반려 이유를 확인할 수 있게 한다.

## 기능별 스펙

### 요청 제출과 승인

- 구성원은 금액, 용도, 증빙을 입력해 요청을 제출한다.
- 사용자 확정: 조직 소유자가 승인 담당자를 지정하고, 담당자 부재 시 사전에 지정된 대리자만 같은 범위에서 처리한다.
- 프로젝트 근거: 현행 기록 보존 정책에 따라 요청과 증빙은 처리일로부터 5년간 보존한 뒤 삭제한다.
- 목표에서 도출: 같은 요청의 중복 처리를 막기 위해 처리 완료 후 재시도는 기존 결과를 반환하고 새 지급 대기를 만들지 않는다.
- 명시적 위임: 같은 상태 안에서 목록 정렬과 강조 방식은 접근성 기준을 지키는 범위에서 구현자가 정한다.

## 실패와 복구

- 반려 시 이유를 구성원에게 보여주고 수정 후 재제출할 수 있다.
- 처리 중 일시 실패하면 요청은 제출 상태를 유지하고 담당자에게 재시도 가능 상태를 보여준다.

## 기술 검토 필요 영역

해당 없음. 중요한 제품·데이터·권한 결정은 위 근거로 닫혔다.
