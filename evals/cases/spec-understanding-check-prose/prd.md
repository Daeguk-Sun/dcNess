# PRD — 읽음 표시 끄기

## 대상 사용자와 범위

- 기존 1:1 대화와 그룹 대화를 쓰는 로그인 사용자.
- 이 epic 은 설정 화면의 "읽음 표시" 선택 1개와 그 선택이 대화 화면에 미치는 동작만 다룬다. 대화 전송·수신·알림 기능은 바꾸지 않는다.

## 목표

사용자가 메시지를 읽었다는 사실을 상대에게 알릴지 스스로 고를 수 있게 한다.

## 기능별 스펙

### 읽음 표시 선택

- 설정 화면에 "읽음 표시" 선택이 있다. 값은 켜짐과 꺼짐 둘이다.
- 선택 값은 계정에 저장되고 같은 계정의 모든 기기에 적용된다.
- 선택 값은 1:1 대화와 그룹 대화에 똑같이 적용된다. 대화방마다 다르게 정할 수 없다.

### 켜짐일 때

- 사용자가 메시지를 읽으면 상대의 대화 화면에 읽음 표시가 나타난다.
- 사용자는 자신이 보낸 메시지에 대한 상대의 읽음 표시를 본다.

### 꺼짐일 때

- 사용자가 메시지를 읽어도 상대의 대화 화면에 읽음 표시가 나타나지 않는다.
- 사용자는 자신이 보낸 메시지에 대한 상대의 읽음 표시도 볼 수 없다. 상대가 읽음 표시를 켜 두었어도 같다.
- 꺼짐으로 바꾸기 전에 이미 표시된 읽음 표시는 지우지 않는다.

### 실패와 복구

- 선택 값 저장이 실패하면 선택은 이전 값으로 돌아가고 오류 문구와 다시 시도 동선을 보여 준다.
- 선택 값을 불러오지 못하면 대화 화면은 마지막으로 확인한 값으로 동작한다.

## 결정과 근거

- **사용자 확정**: 기본값은 켜짐이다. 기존 사용자의 동작을 바꾸지 않는다.
- **사용자 확정**: 대화방별 설정은 만들지 않는다.
- **사용자 확정**: 선택 아래에 안내 문구 한 줄을 둔다.
- **사용자 확정**: 그룹 대화에도 같은 값을 적용한다.
- **사용자 확정**: 꺼짐이면 상대의 읽음 표시도 볼 수 없다.
- **프로젝트 근거**: 선택 값은 기존 계정 설정 저장소에 저장한다. 기존 알림 설정이 같은 저장소를 쓴다.
- **명시적 위임**: 안내 문구의 정확한 글자와 선택의 화면 내 위치는 기존 설정 화면 양식을 지키는 범위에서 구현자가 정한다.

## 권한과 보안

- 사용자는 자신의 선택 값만 읽고 바꾼다.
- 읽음 시각은 선택 값과 무관하게 서버에 기록하지 않는 기존 정책을 유지한다.

## 외부 의존과 운영 제약

- 새 외부 서비스, 비용, 라이선스는 추가하지 않는다.
