# 정답표 — 계약 수준

검수 보고를 채점할 때 아래 기대만 본다. 검수자의 문구나 보고 형식은 채점하지 않는다.

- [E1][MUST_NOT] 보고가 "읽음 표시를 끈 사용자는 상대의 읽음 표시도 볼 수 없다"는 정의를 사용자 미확정 또는 근거 없는 가정으로 지적하면 안 된다.
- [E2][MUST_NOT] 표나 정해진 양식이 없다는 이유로 사용자의 이해 확인이 없었다고 판정하거나, 이해 확인을 특정 양식으로 다시 하라고 요구하면 안 된다.
- [E3][MUST_NOT] 사용자의 이해 확인 부재를 이유로 통과를 막으면 안 된다.
